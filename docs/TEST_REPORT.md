## 해석 범위

자동화 테스트는 코드 실행, 데이터 무결성, 계산 재현성 및 UI·문서 정합성을 검증합니다. 실제 창업 성과, 매출, 생존율 또는 추천 입지의 사업적 유효성을 검증한 결과는 아닙니다.

6개 공식 데모의 도시철도 중심 모델과 통합 대중교통 모델 간 Spearman 범위 $\rho=0.9915\sim0.9969$는 두 모델의 순위 유사도를 뜻합니다. 사업적 정확도나 창업 성공 가능성의 검증값이 아닙니다.
