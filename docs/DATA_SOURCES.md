## 2. 시내버스 데이터 정밀 연계 방법론 (Phase 8 Methodology)

본 서비스의 핵심 개선점인 시내버스 피처 엔지니어링은 다음의 엄격한 데이터 품질 원칙을 준수하여 구축되었습니다.

1. **정류소 물리 위치 및 이용자수 연계**:
   - **물리적 정류소 좌표**: 3,981개소
   - **월별 이용자수 집계 정류소명**: 3,666개
   - **완전 일치(Exact Match)**: 3,624개
   - **정류소명 매칭률**: **98.85%** (미매칭 정류소는 시계 외 정류소 등 극소수)
   - **승하차 볼륨 커버리지**: **99.10%** (대구시 전체 시내버스 승하차량의 99.1%가 공간 좌표에 매핑됨)
2. **품질 정제 기법**:
   - 추측성 매칭으로 인한 데이터 왜곡을 방지하기 위해 **Fuzzy Matching을 전면 배제**하고, 완전 일치 및 정규화(NFC 유니코드 변환, 공백/특수문자 통일)만을 적용했습니다.
   - 동일 정류소명을 공유하는 다중 승강장(Multi-Pole)의 경우, 정류소별 이용자수를 물리적 승강장에 균등 배분(Equal Allocation)하는 보수적 가정을 적용했습니다.
3. **150개 행정동 공간 결합 무결성**:
   - 대구시 150개 전 행정동에 걸쳐 최소 1개소 이상의 버스 정류소가 물리적으로 분포(총 3,981개소 전수 매핑)함을 확인했습니다.
   - **결측 행정동 0건**, **외부 자치구 중앙값 대치 0건**, **임의 800m Fallback 거리 적용 0건**으로, 모델에 투입된 150개 행정동 버스 피처에 해당 대체값이 없습니다.

## 3. 주차 지표에 대한 명확한 성격 규정 (Parking Proxy)

- **데이터 성격**: 본 서비스의 주차 컴포넌트(10%)는 대구광역시 부설주차장 대장 데이터를 기반으로 행정동 단위의 총 주차 인프라 공급 규모를 집계한 **공간적 공급 여건 프록시(Spatial Supply Proxy)** 피처입니다.
- **해석 시 유의사항**:
  - 실시간 주차 가능 면수, 주차장 회전율, 또는 공영주차장 이용률을 직접 나타내는 데이터가 아닙니다.
  - 소상공인 방문 고객의 차량 접근 편의성을 가늠하기 위한 간접적 상대 공급 지표로 해석되어야 합니다.

## 4. 반출 제한 및 미포함 데이터 (Restricted / Future Data)

공모전 규정 및 데이터 보안 준수를 위해 다음 데이터는 본 제출 패키지에 포함되어 있지 않으며, 향후 iM뱅크 및 공공/민간 파트너십을 통해 연계할 확장 로드맵으로 분류되어 있습니다.

| 데이터 명칭 | 분류 | 패키지 미포함 사유 및 처리 방침 |
| :--- | :--- | :--- |
| **카드사 가맹점 실매출 및 소비데이터** | D-데이터허브 안심구역 이용제한 데이터 | 개인정보보호법 및 반출 통제 규정에 따라 원천 데이터 반출 불가. 향후 분석실 내 통계적 집계치 또는 API 모델 연계 추진. |
| **통신사 실시간 생활유동인구 데이터** | 통신사 비공개 민간 데이터 | 고비용 유료 데이터 및 반출 제한으로 미포함. 현재는 행정안전부 주민등록 거주인구 및 대중교통 이용객으로 배후수요 대체 평가. |
| **iM뱅크 소상공인 여신/대출 내부 데이터** | 금융기관 기밀 원천 데이터 | 금융보안 규정에 따라 원천 데이터 접근 불가. 향후 iM뱅크 정식 Open API 제휴를 통해 비대면 심사 로드맵으로 연계 예정. |
| **상가 실거래 임대료 및 공실률 정보** | 부동산 공공/민간 시세 데이터 | 행정동 단위의 신뢰도 높은 공개 시세 부재로 1단계 추천 엔진에서 제외. 향후 한국부동산원 상업용부동산 임대동향 연동 검토. |
