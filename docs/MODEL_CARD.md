# 모델 카드: 대구 소상공인 AI 상권·창업 입지 추천 서비스

- 팀: 말괄량이코물이
- 공모전: 2026 AI Blockchain Challenge in Daegu
- 모델 유형: 공공데이터 기반 MCDM(다기준 의사결정) 상대적 입지 적합도 순위 모델
- 분석 단위: 대구광역시 150개 행정동

## 1. 목적과 출력

사용자가 고른 업종·타깃·가중치 조건으로 150개 행정동의 상대적 입지 적합도(0~100점)와 순위를 산출합니다. 이 점수는 후보지 비교용이며 매출, 수익, 폐업, 대출 승인 또는 창업 성공 확률을 예측하지 않습니다.

## 2. 여섯 컴포넌트

| 컴포넌트 | 기본 가중치 | 정의 |
|---|---:|---|
| 배후수요 | 30% | 주민등록 인구, 인구밀도, 도시철도 승하차, 총 점포수 백분위 결합 |
| 타깃적합 | 20% | 선택 연령층의 비중과 절대 인구 백분위 결합 |
| 경쟁 | 15% | 점포당 타깃인구와 선택 업종 범위의 반경 300m 경쟁점포 백분위 결합 |
| 대중교통 접근성 | 15% | 도시철도 접근성 70% + 시내버스 접근성 30% |
| 주차 | 10% | 부설주차장 공급 여건 Proxy 지표 |
| 업종특화 | 10% | 입지계수 LQ의 150개 행정동 백분위 |

전체 여섯 컴포넌트 가중치는 유지되며 합계 100%입니다. Industry Fit은 동일 정보를 중복 반영하지 않도록 `percentile(LQ)`만 사용합니다. 같은 업종 내에서 도시 전체 업종 비중은 상수이므로 LQ와 행정동 업종 비중은 단조관계입니다.

## 3. 경쟁점포 정의

반경 300m 경쟁점포의 모집단은 사용자가 선택한 업종 집합과 같습니다.

- 음식점: 음식 대분류 전체
- 학원: 일반 교육 + 기타 교육 중분류 결합
- 카페·한식·미용실·종합소매: 선택된 중분류
- 숙박: 숙박 대분류 전체
- 직접 입력: 검색으로 실제 매칭된 대·중분류 집합

각 선택 업종 점포를 기준으로 300m 이내의 다른 선택 업종 점포 수를 세고, 행정동 내 선택 업종 점포들의 평균을 사용합니다. 기준 점포 자체는 제외합니다.

## 4. 점포 미확인 지역 보정

해당 업종 점포가 현재 데이터에서 0개인 지역에는 경쟁점수 할인계수 `α`를 적용합니다. 기본값은 $\alpha=0.50$이며 UI에서 0.00~1.00 범위로 조정할 수 있습니다. 이 보정은 수요가 확인되었다는 뜻이 아니며, 현장 수요·인허가 확인이 필요합니다.

사용자 노출 상태는 다음처럼 중립적으로 표현합니다.

- 해당 업종 점포 확인 지역
- 해당 업종 점포가 적은 지역
- 해당 업종 점포 미확인 지역

## 5. 설명 생성 원칙

설명은 실제 행의 수치로 조립되는 템플릿입니다. LQ가 1.0 이상일 때만 “대구 평균 대비 업종 비중이 상대적으로 높다”고 표현합니다. “시너지”, “성공 가능성”, “검증된 상권”처럼 관측 데이터가 직접 증명하지 못하는 문구는 사용하지 않습니다.

## 6. 모델 비교 해석

모델 비교 탭은 동일한 현재 `α` 조건에서 도시철도 중심 개선 모델과 통합 대중교통 모델을 비교합니다. 할인 적용 전후 비교가 아닙니다.

6개 공식 데모에서 두 모델의 전체 행정동 Spearman 순위 상관계수 범위는 최종 Phase 22 코드·데이터 기준 $\rho=0.9915\sim0.9969$입니다. 이는 두 모델의 순위가 유사하다는 뜻이며 추천 입지의 사업적 정확도 또는 창업 성공 가능성을 의미하지 않습니다.

## 7. 검증 범위

16개 스위트 총 198개 자동화 테스트는 코드 실행, 데이터 무결성, 계산 재현성 및 UI·문서 정합성을 검증합니다. 실제 창업 성과, 매출, 생존율 또는 추천 입지의 사업적 유효성을 검증한 결과는 아닙니다.

## 8. 알려진 한계

- 실제 매출·폐업·생존 ground truth가 없습니다.
- 임대료, 권리금, 실시간 공실률을 포함하지 않습니다.
- 통신사 생활인구 또는 카드 실매출을 포함하지 않습니다.
- 행정동 내부의 필지·골목 차이를 반영하지 못합니다.
- 부설주차장 지표는 공급 Proxy이며 이용 가능 주차면을 뜻하지 않습니다.
- 현장 조사와 인허가·비용 검토가 필요합니다.
- 금융 로드맵 2~4단계는 향후 확장 계획이며 현재 구현은 입지 추천 중심입니다.
