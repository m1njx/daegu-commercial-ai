# [PHASE 6 완료 보고서] 대구 AI 상권 입지 추천 서비스 Prototype 구축

본 보고서는 Phase 5에서 구축되고 독립 코드 감사를 통과한 추천 모델을 기반으로, 실제 심사 및 사용자가 대화형으로 탐색할 수 있는 **사용자 맞춤형 추천 Prototype(Streamlit)** 구축 및 **0개 점포 상권 왜곡 보정(IMPROVED)** 검증 결과를 기술합니다.

## 1. 구현 범위

1. **Phase 5 BASELINE 모델의 무결성 보존**:
   - 기존 `src/recommendation/`의 핵심 알고리즘(`feature_builder.py`, `scoring.py`, `ranking.py`, `explain.py`, `sensitivity.py`)을 단 1줄의 파괴적 수정 없이 그대로 보존.
2. **0개 점포 미진입 상권 왜곡 보정 모듈 (`src/recommendation/improved.py`)**:
   - 특정 업종 점포수가 0개일 때 발생하는 `target_pop / (0 + 1)` 분모 착시 및 무경쟁 최고점 부여 왜곡을 실증 분석.
   - '검증된 상권(점포 $\ge 1$)'과 '미진입/시장 미형성 상권(점포 $0$개)'을 명확히 분류하고 시장 미형성 리스크 할인 계수($\alpha=0.50$)를 적용하는 IMPROVED 모델 개발.
   - 임의의 기준 단일화를 지양하고 다중 임계값($\text{min\_stores} \in [0, 1, 2, 3, 5]$, $\text{discount\_factor} \in [0.0 \sim 1.0]$) 민감도 분석 체계 구현.
3. **사용자 맞춤 가중치 및 개인화 엔진 (`src/recommendation/personalization.py`)**:
   - 6대 컴포넌트(배후 수요, 타깃 적합도, 경쟁 기회도, 교통 접근성, 주차 공급, 업종 특화도)에 대한 사용자 동적 가중치 조절 및 자동 100%(1.0) 정규화.
   - 비음수($\ge 0$) 보장, 비정상 입력 방어, 6대 실전 창업 시나리오 프리셋 제공.
4. **심사위원 1~2분 파악용 대화형 Streamlit Prototype (`app/app.py`)**:
   - 반응형 사이드바(업종, 타깃, 모델 버전, 가중치 프리셋/슬라이더, 개선 파라미터).
   - 메인 대시보드(상권 핵심 지표 카드, 추천 TOP 5 카드 + 세부 점수 및 실제 데이터 기반 추천사유/주의사항).
   - 대구시 150개 행정동 Folium Choropleth 지도 시각화 및 상위 5대 입지 별표 마커 + 94개 도시철도 역사 오버레이.
   - BASELINE vs IMPROVED 정량 비교 탭(Top 10 비교표, Spearman 상관계수, 0점포 동 순위 추적).
   - 150개 행정동 전체 랭킹 검색 및 CSV 다운로드 기능.
5. **정량 비교 분석 및 10대 자동화 테스트 스위트 (`scripts/`)**:
   - `compare_baseline_improved.py`: 주요 5대 업종 + 특화 업종(숙박) 비교 및 JSON 산출물 생성.
   - `run_phase6_tests.py`: 10대 항목(150개 동 무결성, 점수 범위, NaN/Inf 0건, 극단 가중치, 0점포 보정, 입력값 방어, 컴파일) 100% 자동 검증.

## 5. 개인화 추천 로직

사용자가 설정한 6대 요소 가중치 $W = (w_{\text{demand}}, w_{\text{target}}, w_{\text{comp}}, w_{\text{access}}, w_{\text{park}}, w_{\text{ind}})$는 다음과 같은 수학적 방어 및 정규화 파이프라인을 거칩니다.

1. **비음수 클리핑 (Non-negative Clamping)**:
   $$w_i' = \max(0.0, w_i)$$
2. **총합 0 방어 및 Baseline 복원 (Fallback Rule)**:
   $$\sum_{i=1}^6 w_i' \le 0 \implies W_{\text{norm}} = W_{\text{baseline}} = (0.30, 0.20, 0.15, 0.15, 0.10, 0.10)$$
3. **합계 1.0(100%) 정규화 (Simplex Normalization)**:
   $$w_{i, \text{norm}} = \frac{w_i'}{\sum_{j=1}^6 w_j'}$$
4. **가중 총점 결합 (Composite Score)**:
   $$\text{Total Score} = \left( \sum_{i=1}^6 w_{i, \text{norm}} \cdot S_i \right) \in [0.0, 100.0]$$
5. **지원 프리셋 시나리오**:
   - **기본 균형형**: 수요 30%, 타깃 20%, 경쟁 15%, 교통 15%, 주차 10%, 특화 10%
   - **배후 수요 집중형**: 수요 45%, 타깃 15%, 교통 15%, 경쟁 10%, 주차 10%, 특화 5%
   - **타깃 고객 집중형**: 타깃 45%, 교통 15%, 수요 15%, 경쟁 10%, 특화 10%, 주차 5%
   - **교통/유동인구 우선형**: 교통 35%, 수요 20%, 타깃 15%, 경쟁 10%, 주차 10%, 특화 10%
   - **경쟁 회피(블루오션)형**: 경쟁 40%, 수요 20%, 타깃 15%, 교통 10%, 특화 10%, 주차 5%
   - **주차/차량 방문 중심형**: 주차 40%, 수요 20%, 타깃 10%, 경쟁 10%, 교통 10%, 특화 10%

## 6. 업종 0개 지역 처리 결과

### 6.1 실증 데이터 진단 (Audit Finding Verification)
대구시 150개 행정동 전수 데이터를 바탕으로 업종별 점포 0개 행정동 현황을 정량 조사하였습니다.

- **일상 필수 업종 (카페, 한식, 종합소매)**:
  - 150개 행정동 전체에서 해당 업종 점포수가 $\ge 1$개 이상(최소 2개~최대 396개) 존재.
  - **점포 0개 행정동 수 = 0개 (0.0%)**. 즉, 일상 업종에서는 0점포 착시 현상이 자연적으로 발생하지 않음.
- **전문/특화 업종 (숙박, 학원, 미용실)**:
  - 미용실: 점포 0개 행정동 1개 (군위군 삼국유사면)
  - 학원: 점포 0개 행정동 4개 (서구 비산6동, 군위군 의흥면, 군위군 우보면, 군위군 산성면)
  - **숙박(호텔·모텔·여관)**: **점포 0개 행정동 23개 (15.3%)** 존재.

### 6.2 Baseline 모델에서의 문제점 실증
숙박 업종의 Phase 5 Baseline 추천 결과:
- **3위: 달서구 용산1동** (숙박 점포수 **0개**, 경쟁점수 **90.78점**, 총점 **73.36점**)
- **4위: 달서구 상인1동** (숙박 점포수 **0개**, 경쟁점수 **90.44점**, 총점 **72.96점**)

> **원인 분석**: 용산1동과 상인1동은 대단지 아파트 밀집 주거지역으로 학교보건위생정화구역 및 주거지역 용도지역 제한에 따라 숙박업소가 법적·상업적으로 진입할 수 없는 지역입니다. 그러나 Baseline 수식인 $\text{target\_pop} / (0 + 1)$과 $\text{comp\_300m} = 0$이 결합되면서 **"경쟁점이 없는 블루오션 상권"으로 오판되어 Top 5에 랭크되는 심각한 착시**가 발생하였습니다.

### 6.3 IMPROVED 모델 보정 메커니즘
1. **상권 상태 태깅 (Market Status)**:
   - 해당 업종 점포수 $\ge 1$인 경우: `"검증된 상권"`
   - 해당 업종 점포수 $= 0$인 경우: `"미진입 상권 (점포 0개)"`
2. **시장 형성 리스크 할인 계수 적용 ($\alpha = 0.50$)**:
   $$\text{Competition Score}_{\text{improved}} = \begin{cases} \text{Competition Score}_{\text{raw}} & (\text{점포수} \ge 1) \\ \text{Competition Score}_{\text{raw}} \times 0.50 & (\text{점포수} = 0) \end{cases}$$
3. **보정 후 순위 변화**:
   - **용산1동 (0개)**: Baseline 3위(73.36점) $\to$ **Improved 15위(66.55점)** (-12계단 정상 하락)
   - **상인1동 (0개)**: Baseline 4위(72.96점) $\to$ **Improved 16위(66.18점)** (-12계단 정상 하락)
   - **실제 숙박 상권의 Top 5 진입**:
     - **3위: 동구 안심4동** (숙박업소 3개, 72.55점)
     - **4위: 동구 신암4동** (동대구역 복합환승센터 핵심 숙박 클러스터, 숙박업소 **36개**, 72.19점)
     - **5위: 수성구 범어1동** (범어네거리 중심 상업지구, 숙박업소 3개, 71.42점)

## 10. 지도 구현

대구광역시 150개 행정동 공간 경계 GeoJSON(`대구_행정동_경계_20230701.geojson`)과 `Folium` 엔진을 연동하여 웹 브라우저에서 대화형으로 구동됩니다.

1. **행정동 단계구분도 (Choropleth Layer)**:
   - 각 행정동 폴리곤을 입지 적합도 점수($0.0 \sim 100.0$)에 따라 `YlOrRd`(Yellow-Orange-Red) 컬러맵으로 음영 시각화.
   - 점수가 높을수록 붉은색, 낮을수록 노란색/연한색으로 매핑되어 상권 잠재력 분포를 직관적으로 파악 가능.
2. **추천 TOP 5 강조 마커 (Numbered Star Markers)**:
   - 투영 좌표계(EPSG:5179) 기반 정밀 도심 중심점(Centroid) 계산을 통해 상위 5대 추천 동 위치에 순위별 색상 마커(1위 Red, 2위 Darkred, 3위 Orange, 4위 Green, 5위 Blue) 표시.
   - 마커 클릭 시 팝업 창에 `순위`, `행정동명`, `입지 적합도 점수`, `해당 업종 점포수` 렌더링.
3. **도시철도 인프라 오버레이 (Metro Layer Toggle)**:
   - 사용자가 체크박스를 활성화하면 대구도시철도 94개 역사의 위경도 좌표가 서클 마커로 즉시 중첩 표기되어 역세권 입지 여부를 시각적으로 교차 검증 가능.

## 12. 오류 및 해결 내용

1. **CartoDB 타일 API Key 요구 경고**:
   - **현상**: Folium 지도 렌더링 시 `UserWarning: CartoDB tiles now require an API key.` 발생.
   - **해결**: 외부 API 키 등록이 필요 없는 표준 오픈소스 타일인 `tiles="OpenStreetMap"`으로 전면 전환하여 독립 실행 보장 및 API 키 유출 위험 차단.
2. **지리 좌표계 Centroid 계산 편차 경고**:
   - **현상**: EPSG:4326(경위도) 상태에서 `gdf.centroid` 호출 시 `UserWarning: Geometry is in a geographic CRS.` 발생.
   - **해결**: 대한민국 표준 평면투영 좌표계인 `EPSG:5179`(UTM-K)로 변환 후 Centroid를 계산하고 이를 다시 `EPSG:4326`으로 변환(`gdf.to_crs(epsg=5179).centroid.to_crs(epsg=4326)`)하여 수 미터 이내 정밀 좌표 확보 및 경고 해소.
3. **테스트 스크립트 Unpacking 인자 수 불일치**:
   - **현상**: `run_phase6_tests.py` Test 8에서 `build_dong_industry_features`의 반환값이 2개(`feat`, `meta`)이나 3개로 언패킹을 시도하여 `ValueError: not enough values to unpack` 발생.
   - **해결**: 2개 튜플 언패킹(`feat_fb, meta_fb`)으로 즉시 수정하여 자동화 테스트 100% 정상 통과 완료.
4. **포트 충돌(Port 8501 is not available)**:
   - **현상**: 로컬 환경에서 기존 프로세스가 8501 포트를 점유하고 있어 실행 오류 발생.
   - **해결**: 가용 포트인 8502로 전환(`--server.port 8502`)하여 정상 구동 확인(HTTP 200 OK 수신).

## 13. 남은 한계 및 데이터 범위

1. **상업용 전용 주차장 부재 (Proxy 지표 한계)**:
   - 주차 점수는 건축물대장 기반 '부설주차장 수용능력' proxy이므로, 실제 상가 방문객이 무료로 이용 가능한 전용 고객 주차장 여부는 현장 실사가 필요합니다.
2. **동별 정적 데이터 기반 (실시간 유동인구 부재)**:
   - 도시철도 승하차 인원은 포함되었으나 통신사 실시간 생활인동 데이터는 원천 데이터에 없으므로 시간대별(점심/저녁/주말) 유동인구 세분화는 향후 과제입니다.
3. **비용 및 임대료 데이터 미반영**:
   - 상가 권리금, 보증금, 평당 임대료 데이터는 공공 무료 데이터셋 범위에 포함되지 않아, 최종 입지 선정 시 예산에 따른 필터링은 사용자가 직접 병행해야 합니다.
4. **미진입 상권의 이중성**:
   - 0개 점포 지역은 제도적 규제(학교환경보호구역 등)나 수요 부재일 수도 있으나, 드물게 신도시 입주 초기의 선점 기회일 수도 있습니다. 본 서비스는 이를 자동 단정하지 않고 사용자에게 '주의사항'으로 투명하게 안내합니다.
