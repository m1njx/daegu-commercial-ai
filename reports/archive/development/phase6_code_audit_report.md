## 2. 종합 의견

Phase 6 구현물은 Phase 5에서 지적된 "0개 점포 지역의 무경쟁 착시($\text{target\_pop}/(0+1)$로 인한 점수 과대계상)" 문제를 해결하기 위해 시장 미형성 리스크 할인 계수($\alpha=0.50$)와 상권 상태 태깅(`검증된 상권` vs `미진입 상권`)을 도입하였으며, 이를 사용자 맞춤형 가중치 엔진과 결합하여 심사위원이 1~2분 내에 조작할 수 있는 Streamlit 대화형 웹 Prototype으로 성공적으로 패키징하였습니다.

특히, 숙박 업종에서 기존 Baseline 3위(용산1동, 점포 0개)와 4위(상인1동, 점포 0개)가 아파트 밀집 주거지역임에도 상위권에 랭크되던 치명적인 상권 왜곡이 Improved 모델에서 15위, 16위로 정상 하락하고, 실제 동대구역 숙박 클러스터(신암4동, 점포 36개)가 Top 5로 진입하는 정량적 개선 효과가 실증되었습니다.

다만, 보고서 작성 과정에서 실제 JSON 및 Parquet 결과를 100% 정밀하게 복사하지 않고 일부 텍스트를 오기입한 점, 그리고 UI 코드 내 보조 레이어(지하철 마커)의 컬럼 매핑 오류는 최종 제출 및 배포 전에 반드시 교정되어야 합니다.

## 5. IMPROVED 모델 검증

`src/recommendation/improved.py`의 핵심 계산 로직을 정밀 분석하였습니다.

### A. 0개 점포 처리 및 할인 계수 $\alpha$의 작동 위치
- **$\alpha$의 정의**: Line 23 `DEFAULT_DISCOUNT_FACTOR: float = 0.50` 및 Line 30 파라미터 `discount_factor`로 선언됨. 상수가 아닌 가변 인자로 설계되어 호출 시 임의 변경 가능.
- **적용 조건**: Line 109~111
  $$\text{is\_unentered} = (\text{cat\_store\_count} < \text{min\_stores}) \lor (\text{total\_stores} < \text{min\_total\_stores})$$
  기본값(`min_stores=1`, `min_total_stores=0`) 설정 시, 관내 해당 업종 점포가 0개일 때 정확히 트리거됨.
- **적용 대상**: Line 120~124
  $$\text{adjusted\_comp\_score} = \begin{cases} \text{raw\_comp\_score} \times \alpha & (\text{is\_unentered} = \text{True}) \\ \text{raw\_comp\_score} & (\text{is\_unentered} = \text{False}) \end{cases}$$
  $\alpha$는 최종 종합점수에 직접 곱해지는 것이 아니라, **경쟁 환경 기회 점수(`competition_score`)에만 국소적으로 적용**됨.
- **순위 산출 시점**: 보정된 `competition_score`가 가중 합산되어 `total_score`를 형성한 후, 최종 `rank_locations`에 의해 정렬되므로 **순위 산출 전에 정상 반영**됨.

### B. 0점포 지역의 상태 태깅 (Market Status)
- Line 113~117:
  - `검증된 상권`: 점포수 $\ge 1$개
  - `미진입 상권 (점포 0개)`: 점포수 $= 0$개
  - `미검증 소규모 상권`: 총 점포수 미달
- **단순 표시 여부**: 단순 UI 배지 문자열 표시뿐만 아니라, `is_unentered` 불리언 플래그가 실제 경쟁 점수 감점($\times \alpha$) 및 `filter_unentered=True` 시 랭킹 완전 배제 로직과 직접 연동됨.

### C. 0점포가 아닌 지역에 대한 영향
- 점포수 $\ge 1$인 지역에서는 $\text{adjusted\_comp\_score} = \text{raw\_comp\_score}$가 유지되며, 나머지 5개 컴포넌트 점수도 동일한 백분위수 공식을 따르므로 **비(非)0점포 지역의 원시 점수는 BASELINE과 100% 동일**함.

## 6. $\alpha = 0.50$ 전략적 타당성 검토

### 1. 데이터 기반 근거 유무
- **판정: 데이터 기반 최적화 계수가 아닌 '휴리스틱 정책 파라미터' (Policy Heuristic)**.
- 실제 소상공인 폐업률, 3년 생존율, 실매출 등의 Ground Truth 레이블이 원천 데이터에 존재하지 않으므로, 머신러닝 목적함수(Loss Minimization)로 도출된 값이 아님.

## 9. Personalization 검증

`src/recommendation/personalization.py`의 입력 방어 및 정규화 로직을 실제 테스트 케이스로 실행하였습니다:

1. **음수 가중치 차단**: `demand = -50` 입력 시 `max(0.0, -50.0) = 0.0`으로 정상 클리핑됨 확인.
2. **가중치 합계 1.0 정규화**: 임의의 합계(예: 합계 300, 합계 21 등)에 대해 모든 가중치를 `val / total`로 나누어 정확히 1.0(100%)을 도출함 확인.
3. **전부 0 입력 시 Fallback**: 모든 가중치가 0인 비정상 입력 시 `BASELINE_WEIGHTS`로 자동 복원됨 확인.
4. **극단값 단일 가중치 재랭킹 실측**:
   - `Demand 100%`: 달서구 감삼동 1위 (총점 92.55 == 수요점수 92.55)
   - `Target Fit 100%`: 달서구 신당동(계명대 대학가) 1위 (총점 94.77 == 타깃점수 94.77)
